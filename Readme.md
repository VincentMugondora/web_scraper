# Job Scraping Script

This Python script uses Selenium to scrape job listings from the website [vacancymail.co.zw](https://vacancymail.co.zw/jobs/). The data collected is saved into a CSV file for further analysis or use.

## Requirements

Before running the script, you need to have the following dependencies installed:

- **Python** (version 3.x)
- **Selenium**: A tool for automating web browsers.
- **ChromeDriver**: A WebDriver for Chrome used by Selenium to control the browser.
- **Pandas**: A powerful data manipulation and analysis library.
- **Chrome Browser**: Ensure that Google Chrome is installed on your system.

You can install the required libraries using `pip`:

```bash
pip install selenium pandas
